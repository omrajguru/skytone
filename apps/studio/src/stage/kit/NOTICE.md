# Stageshow kit

This folder is the React kit from [Stageshow](https://github.com/benjitaylor/skills) by Benji Taylor, used under the MIT License in `LICENSE`. Skytone uses it for the animated product demo on its home page.

Changes from upstream: the brand-logo registry (`brands/`) and the `BrandMark` part are removed, and one icon import is renamed for lucide-react 1.x.
